Alien AI Trader — Quick Startup Instructions
============================================

WHAT THIS APP DOES
------------------
Alien AI Trader includes an installer that sets up Python, installs the app,
walks you through API keys, and creates a Desktop shortcut for you.

FOR MOST NEW USERS — DO THIS
----------------------------
1. Go to the GitHub Releases page for Alien AI Trader
2. Download the latest ZIP file
3. Right-click the ZIP and choose "Extract All"
4. Open the extracted Alien_AI_Trader folder
5. Double-click: LAUNCH.bat
6. Choose: [1] Install
7. Follow the on-screen setup wizard

AFTER INSTALL
-------------
1. Double-click the "Alien AI Trader" shortcut on your Desktop
   OR open the install folder and double-click START.bat
2. Your browser should open automatically
3. Local dashboard address: http://localhost:5000

IF SOMEONE WANTS THE FILES FROM GIT INSTEAD
-------------------------------------------
1. Install Git for Windows: https://git-scm.com/download/win
2. Open Command Prompt or PowerShell
3. Run:

   git clone https://github.com/T-Dubs-Apps/Alien-AI-Trader.git

4. Open the downloaded Alien-AI-Trader folder
5. Double-click ONE_CLICK_INSTALL.bat

EASIEST SINGLE-FILE METHOD
--------------------------
If you were sent DOWNLOAD_AND_INSTALL.bat:
1. Double-click it
2. If Git is missing, install Git when prompted
3. Double-click DOWNLOAD_AND_INSTALL.bat again
4. It downloads the repo to your Desktop and starts the installer

KEYS YOU WILL BE ASKED FOR
--------------------------
- ALPACA_KEY + ALPACA_SECRET
- ALPHA_VANTAGE_KEY
- PUSHOVER_TOKEN + PUSHOVER_USER (optional)
- TWILIO settings (optional)
- PUSHBULLET_API_KEY (optional)

IMPORTANT TIP
-------------
Start with Alpaca Paper Trading first. It uses fake money and is much safer for
new users than live trading.
