Alien AI Trader — Simple Download and Install Instructions
==========================================================

For most people, the easiest install process is:

1. Download the latest Alien AI Trader ZIP from GitHub Releases
2. Right-click the ZIP and choose "Extract All"
3. Open the extracted folder (named Alien-AI-Trader-main or similar)
4. Double-click LAUNCH.bat
5. Choose [1] Install
6. Follow the setup wizard

The installer will:
- Install Python if needed
- Install the app files and packages
- Open the signup pages for the services you need
- Save your keys automatically
- Create a Desktop shortcut

After setup, start the app by double-clicking:
- Alien AI Trader on your Desktop
or
- START.bat inside the install folder

If you want the app to download itself first, use DOWNLOAD_AND_INSTALL.bat.
